# Socket_Painter

在 Android Studio 開發的多人即時共同編輯小畫家，透過 Socket 讓多台裝置同步繪圖。

## 功能
* 即時多人畫布同步
* 畫筆顏色與粗細調整、橡皮擦、清除畫布
* 支援建立連線（Server）與輸入 IP 加入（Client）

## 技術棧
* Android Studio / Kotlin or Java
* Socket 網路通訊
* Android `Canvas` / `Paint`
